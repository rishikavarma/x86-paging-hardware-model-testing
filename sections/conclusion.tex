\section{Conclusion}\label{sec:conclusion}
%% ============================================================

% TODO: Summarise contributions and outline future work.
In this paper, we presented a proof-of-concept model validation strategy for the x86 paging hardware. We proposed a reduction argument to reduce the testing space and a method to generate a set of test cases that cover the behaviours we are interested in. We also proposed a way to analyse the observable traces to identify if they are allowed by the model through synthesis. These ideas can be extended to a more accurate and comprehensive model and also include more robust proofs for the reduction arguments which we leave this for future work.
